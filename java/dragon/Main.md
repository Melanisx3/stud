# Main — запуск программы и взаимодействие с пользователем

[Исходный файл Main.java](../Main.java)

## 1. Назначение класса

Main — главный класс программы. Он содержит точку входа main(), организует последовательность выполнения всех частей проекта и сохраняет результаты заданий в текстовые файлы.

Основные обязанности:

1. Получить параметры запуска из аргументов командной строки или интерактивного ввода.
2. Проверить параметры генерации.
3. Создать каталог для результатов.
4. Сгенерировать драконов.
5. Выполнить задания 1–11.
6. Подготовить текстовые результаты.
7. Записать результаты в файлы task0.txt–task11.txt.
8. Вывести сообщение об окончании работы.

## 2. Поле opts

~~~java
private static Map<String, String> opts = new HashMap<>();
~~~

Хранит параметры программы в виде пар ключ-значение.

- ключ String — название параметра;
- значение String — введённое пользователем значение.

Пример содержимого:

~~~text
count -> 70
seed -> 42
speedThreshold -> 80
out -> out
~~~

Используется HashMap, потому что порядок параметров не имеет значения. По ключу можно быстро получить нужное значение.

Поле static, поэтому доступно всем статическим методам Main без создания объекта.

## 3. Метод num(String key, int def)

~~~java
private static int num(String key, int def) {
    return Integer.parseInt(opts.getOrDefault(key, String.valueOf(def)));
}
~~~

Метод получает числовой параметр из opts.

Параметры:

- key — String, название параметра;
- def — int, значение по умолчанию.

Возвращает int.

Порядок работы:

1. opts.getOrDefault(key, ...) пытается получить значение по ключу.
2. Если ключ отсутствует, используется значение по умолчанию.
3. String.valueOf(def) преобразует число def в строку.
4. Integer.parseInt() преобразует полученную строку обратно в int.

Например, num("count", 70) вернёт число 70, если параметр count не был задан.

Если значение в opts не является корректным целым числом, Integer.parseInt() выбросит NumberFormatException.

## 4. Метод main(String[] args)

~~~java
public static void main(String[] args) throws IOException
~~~

Это точка входа в Java-программу.

Параметр:

- args — String[], массив аргументов командной строки.

Возвращаемый тип: void, метод ничего не возвращает.

throws IOException означает, что метод может передать исключение ввода-вывода вызывающему коду. В данном случае это связано с созданием каталогов и записью файлов.

### Шаг 1. Чтение аргументов командной строки

~~~java
for (String a : args) {
    String[] kv = a.split("=", 2);
    if (kv.length == 2) opts.put(kv[0], kv[1]);
}
~~~

- for-each перебирает каждый аргумент массива args.
- split("=", 2) делит строку по первому знаку = максимум на две части.
- kv[0] — ключ;
- kv[1] — значение.
- opts.put() сохраняет пару в HashMap.

Пример запуска:

~~~bash
java Main count=100 seed=15 speedThreshold=70
~~~

В opts будут сохранены три параметра.

Если аргумент не содержит =, он игнорируется.

### Шаг 2. Выбор способа ввода

~~~java
if (args.length == 0) {
    askInteractively();
}
~~~

Если аргументы командной строки отсутствуют, программа запускает интерактивный ввод.

Если хотя бы один аргумент присутствует, askInteractively() не вызывается.

### Шаг 3. Создание каталога

~~~java
Path dir = Path.of(opts.getOrDefault("out", "out"));
Files.createDirectories(dir);
~~~

- Path — тип, представляющий путь к файлу или каталогу.
- Path.of() создаёт объект пути из строки.
- getOrDefault() получает каталог из параметра out или использует out по умолчанию.
- Files.createDirectories() создаёт каталог и все отсутствующие родительские каталоги.

Если каталог уже существует, повторное создание не является ошибкой.

### Шаг 4. Генерация драконов — задание 0

~~~java
var params = new DragonGenerator.Params(
        num("count", 70),
        num("minHeads", 1),
        num("maxHeads", 5),
        num("minSpeed", 10),
        num("maxSpeed", 100),
        num("minPower", 10),
        num("maxPower", 100)
);

List<Dragon> dragons =
        new DragonGenerator(num("seed", 42)).generate(params);
~~~

Создаётся запись Params с параметрами генерации.

var — локальная переменная с автоматически определяемым компилятором типом. В данном случае фактический тип params — DragonGenerator.Params.

Затем создаётся DragonGenerator с указанным seed и вызывается generate().

Результат сохраняется в List<Dragon>.

### Шаг 5. Запись исходных драконов

~~~java
write(dir, 0, dragons.stream().map(Dragon::toString).toList());
~~~

Для каждого дракона вызывается toString(), затем результаты собираются в List<String> и записываются в task0.txt.

## 5. Метод askInteractively()

~~~java
private static void askInteractively()
~~~

Метод организует ввод параметров через консоль.

Параметры: отсутствуют.

Возвращаемый тип: void.

### Порядок работы

1. Создаётся Scanner для чтения System.in.
2. Выводится инструкция: пустой Enter означает значение по умолчанию.
3. Запрашиваются параметры генератора.
4. После ввода параметров создаётся временный DragonGenerator.Params, чтобы выполнить проверки диапазонов.
5. Если конструктор выбрасывает IllegalArgumentException, пользователю показывается сообщение и параметры генерации запрашиваются заново.
6. После успешной проверки запрашивается seed.
7. Запрашиваются параметры заданий.
8. Для avgLo и avgHi отдельно проверяется, что нижняя граница не больше верхней.
9. Запрашивается разделитель имён для задания 11.

### Почему используется while(true)?

Цикл позволяет повторять ввод, пока пользователь не введёт допустимые значения.

Выход выполняется через break после успешной проверки.

### Используемый Scanner

Scanner — класс java.util.Scanner, который позволяет читать текст из источника ввода.

В данном случае источник — System.in, стандартный поток ввода с клавиатуры.

## 6. Метод ask()

~~~java
private static void ask(
        Scanner sc,
        String key,
        String label,
        int def,
        int min
)
~~~

Метод запрашивает одно целое число и сохраняет его в opts.

| Параметр | Тип | Назначение |
|---|---|---|
| sc | Scanner | Объект чтения ввода |
| key | String | Ключ параметра в opts |
| label | String | Текст вопроса пользователю |
| def | int | Значение по умолчанию |
| min | int | Минимально допустимое значение |

Возвращаемый тип: void.

### Пошаговая работа

1. while(true) запускает повторный запрос.
2. System.out.print() показывает название параметра и значение по умолчанию.
3. hasNextLine() проверяет наличие следующей строки.
4. Если ввод завершился, в opts сохраняется значение по умолчанию.
5. nextLine() считывает строку.
6. trim() удаляет пробелы по краям.
7. Если строка пустая, сохраняется значение по умолчанию.
8. Integer.parseInt() пытается преобразовать строку в int.
9. Если число меньше min, выводится ошибка и цикл начинается заново.
10. Если число допустимо, оно преобразуется в String и сохраняется в opts.
11. Если возник NumberFormatException, выводится сообщение о необходимости ввести целое число.

### Обработка исключения

~~~java
try {
    int value = Integer.parseInt(line);
    ...
} catch (NumberFormatException e) {
    System.out.println("  Нужно целое число.");
}
~~~

NumberFormatException возникает, если введённая строка не может быть преобразована в целое число.

Исключение перехватывается, программа не завершается аварийно, а предлагает повторить ввод.

## 7. Метод write()

~~~java
private static void write(Path dir, int task, List<String> lines)
        throws IOException
~~~

Записывает результат одного задания в текстовый файл.

Параметры:

- dir — Path, каталог для сохранения;
- task — int, номер задания;
- lines — List<String>, строки, которые нужно записать.

Возвращаемый тип: void.

Алгоритм:

1. dir.resolve("task" + task + ".txt") формирует путь к файлу.
2. Files.write() записывает список строк в файл.
3. Если файл уже существует, Files.write() по умолчанию заменяет его содержимое.
4. Если возникает ошибка ввода-вывода, она передаётся вызывающему коду через throws IOException.

Например:

~~~java
write(dir, 2, lines);
~~~

Запишет данные в task2.txt внутри указанного каталога.

## 8. Метод print()

~~~java
private static void print(
        Object value,
        List<String> out,
        int level,
        String... keyNames
)
~~~

Универсальный метод для преобразования вложенных Map и Collection в список строк.

Параметры:

| Параметр | Тип | Назначение |
|---|---|---|
| value | Object | Объект для вывода: карта или коллекция |
| out | List<String> | Список, в который добавляются строки |
| level | int | Уровень вложенности |
| keyNames | String... | Названия уровней ключей |

String... означает переменное количество строковых аргументов. Внутри метода keyNames используется как массив String[].

Возвращаемый тип: void. Метод изменяет переданный список out, добавляя в него строки.

### Шаг 1. Формирование отступа

~~~java
String indent = "  ".repeat(level);
~~~

repeat(level) повторяет строку с двумя пробелами указанное количество раз.

Это нужно для визуального отображения вложенных групп.

### Шаг 2. Проверка Map

~~~java
if (value instanceof Map<?, ?> m)
~~~

instanceof проверяет, является ли объект картой.

Map<?, ?> означает, что типы ключей и значений заранее неизвестны.

Если проверка успешна, переменная m получает ссылку на карту.

### Шаг 3. Выбор названия ключа

~~~java
String label = level < keyNames.length
        ? keyNames[level]
        : "key";
~~~

Используется тернарный оператор.

Если для текущего уровня задано название, оно берётся из массива keyNames. Иначе используется универсальное слово key.

### Шаг 4. Перебор карты

~~~java
m.forEach((k, v) -> {
    ...
});
~~~

forEach() перебирает пары ключ-значение.

- k — текущий ключ;
- v — текущее значение.

### Шаг 5. Преобразование Boolean

~~~java
String key = k instanceof Boolean b
        ? (b ? "да" : "нет")
        : String.valueOf(k);
~~~

Если ключ является Boolean, true преобразуется в да, false — в нет.

В остальных случаях String.valueOf() преобразует ключ в строку.

### Шаг 6. Проверка вложенной структуры

~~~java
if (v instanceof Map<?, ?> || v instanceof Collection<?>)
~~~

Проверяется, является ли значение ещё одной картой или коллекцией.

Если это так:

1. Определяется количество элементов.
2. Добавляется строка с названием группы, ключом и размером.
3. print() вызывается рекурсивно для вложенной структуры с увеличенным level.

### Что такое рекурсия?

Рекурсия — вызов метода из самого себя.

Здесь она позволяет обрабатывать карты с произвольным количеством вложенных уровней, не создавая отдельный метод для каждого уровня.

### Шаг 7. Вывод элементов коллекции

~~~java
} else if (value instanceof Collection<?> c) {
    c.forEach(e -> out.add(indent + e));
}
~~~

Если текущий объект является коллекцией, каждый её элемент преобразуется в строку и добавляется в out.

## 11. Обработка ошибок и ограничения текущей реализации

- ask() обрабатывает NumberFormatException при интерактивном вводе целого числа.
- askInteractively() перехватывает IllegalArgumentException при проверке Params.
- main() объявляет throws IOException, поэтому ошибки файловой системы могут завершить выполнение с исключением.
- При запуске с аргументами командной строки ask() не вызывается. Поэтому некорректное числовое значение может привести к NumberFormatException в num().
- Проверка диапазонов Params выполняется при создании DragonGenerator.Params.
- Проверка avgLo <= avgHi выполняется только в интерактивном режиме. При передаче аргументов командной строки это условие отдельно не проверяется.
- Для n в интерактивном режиме установлена минимальная граница 1. При передаче аргументов командной строки аналогичная проверка отсутствует.
- Метод print() рассчитан на Map и Collection. Для других типов объектов он не добавляет строку в out.
