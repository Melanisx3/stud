# DragonGenerator — генератор драконов

[Исходный файл DragonGenerator.java](../DragonGenerator.java)

## 1. Назначение класса

DragonGenerator создаёт список объектов Dragon с заданными параметрами.

Генератор отвечает за:

- количество создаваемых драконов;
- количество голов каждого дракона;
- скорости передвижения;
- мощность голов;
- распределение по 14 видам;
- случайное перемешивание готового списка.

Класс не выполняет задания над драконами. Он только формирует исходные данные, которые затем передаются в DragonTasks.

## 2. Вложенная запись Params

~~~java
public record Params(
        int count,
        int minHeads,
        int maxHeads,
        int minSpeed,
        int maxSpeed,
        int minPower,
        int maxPower
) { ... }
~~~

Params — вложенная запись (record), предназначенная для хранения параметров генерации.

Record автоматически создаёт конструктор, методы доступа с именами компонентов, а также equals(), hashCode() и toString().

В отличие от обычного класса, запись не требует вручную объявлять поля и геттеры для этих компонентов.

| Компонент | Тип | Значение |
|---|---|---|
| count | int | Количество драконов |
| minHeads | int | Минимальное количество голов |
| maxHeads | int | Максимальное количество голов |
| minSpeed | int | Минимальная скорость |
| maxSpeed | int | Максимальная скорость |
| minPower | int | Минимальная мощность головы огнедышащего дракона |
| maxPower | int | Максимальная мощность головы огнедышащего дракона |

### Компактный конструктор Params

~~~java
public Params {
    if (count < 0) throw new IllegalArgumentException("count < 0");
    if (minHeads < 1 || maxHeads < minHeads) throw new IllegalArgumentException("неверный диапазон голов");
    if (minSpeed < 0 || maxSpeed < minSpeed) throw new IllegalArgumentException("неверный диапазон скоростей");
    if (minPower < 1 || maxPower < minPower) throw new IllegalArgumentException("неверный диапазон мощности (min >= 1)");
}
~~~

Это компактный конструктор record. Он выполняется при создании Params и проверяет входные значения.

Проверки:

1. count не может быть отрицательным. Ноль допустим.
2. minHeads должен быть не меньше 1.
3. maxHeads должен быть не меньше minHeads.
4. minSpeed не может быть отрицательным.
5. maxSpeed должен быть не меньше minSpeed.
6. minPower должен быть не меньше 1.
7. maxPower должен быть не меньше minPower.

Если условие нарушено, выбрасывается IllegalArgumentException. Благодаря этому некорректные параметры не попадут в генератор.

## 3. Константа KINDS

~~~java
private static final int KINDS = 14;
~~~

Определяет количество видов драконов.

У дракона может быть одна из семи непустых комбинаций умений:

1. только LAND;
2. только FLY;
3. только SWIM;
4. LAND + FLY;
5. LAND + SWIM;
6. FLY + SWIM;
7. LAND + FLY + SWIM.

Каждая комбинация встречается в двух вариантах: огнедышащий дракон и дракон без огнедышащей способности.

Итого: 7 × 2 = 14 видов.

## 4. Поле random

~~~java
private final Random random;
~~~

Random — класс стандартной библиотеки Java для генерации псевдослучайных чисел.

Поле final: после создания генератора ссылка random не переназначается.

Один экземпляр Random используется во всех операциях генерации и перемешивания. Это позволяет последовательно получать значения из одной псевдослучайной последовательности.

## 5. Конструктор DragonGenerator

~~~java
public DragonGenerator(long seed) {
    this.random = new Random(seed);
}
~~~

Принимает параметр seed типа long.

Seed — начальное значение генератора псевдослучайных чисел.

Если создать два генератора с одинаковым seed и выполнить одинаковую последовательность операций, они воспроизведут одинаковую последовательность псевдослучайных значений.

Это полезно для повторяемых экспериментов и проверки результатов программы.

Пример:

~~~java
DragonGenerator first = new DragonGenerator(42);
DragonGenerator second = new DragonGenerator(42);
~~~

## 6. Метод generate(Params p)

~~~java
public List<Dragon> generate(Params p)
~~~

Главный публичный метод класса. Создаёт и возвращает список драконов.

Параметр:

- p — объект DragonGenerator.Params, содержащий все настройки генерации.

Возвращаемый тип:

- List<Dragon> — список созданных объектов Dragon.

### Пошаговая работа

1. IntStream.range(0, p.count()) создаёт поток целых индексов от 0 включительно до count не включительно.
2. mapToObj(i -> create(i, p)) преобразует каждый индекс в объект Dragon, вызывая метод create().
3. collect(Collectors.toCollection(ArrayList::new)) собирает объекты в новый ArrayList.
4. Collections.shuffle(dragons, random) случайным образом перемешивает список, используя тот же объект Random.
5. return dragons возвращает готовый список.

### Используемые конструкции

**IntStream.range(start, end)**

Создаёт поток целых чисел от start до end - 1.

Если count равен 5, будут обработаны индексы 0, 1, 2, 3, 4.

**mapToObj()**

Преобразует примитивный поток IntStream в поток объектов Stream<Dragon>.

**collect()**

Выполняет терминальную операцию потока и собирает результат в коллекцию.

**Collectors.toCollection(ArrayList::new)**

Указывает, что результат необходимо собрать в новый ArrayList. ArrayList::new — ссылка на конструктор, используемая как поставщик нового списка.

**Collections.shuffle()**

Перемешивает элементы уже созданного списка. Перемешивание не создаёт новых драконов и не меняет характеристики объектов.

## 7. Приватный метод create(int index, Params p)

~~~java
private Dragon create(int index, Params p)
~~~

Создаёт одного дракона по его индексу и параметрам генерации.

Параметры:

| Параметр | Тип | Назначение |
|---|---|---|
| index | int | Порядковый индекс создаваемого дракона, начиная с 0 |
| p | Params | Настройки генерации |

Возвращает один объект Dragon.

### Шаг 1. Определение вида

~~~java
int kind = index % KINDS;
~~~

Оператор % вычисляет остаток от деления.

Так как KINDS равен 14, переменная kind принимает значения от 0 до 13. После каждых 14 индексов цикл видов повторяется.

### Шаг 2. Определение умений

~~~java
int abilities = (kind % 7) + 1;
~~~

Выражение формирует числа от 1 до 7 — все непустые комбинации трёх битовых умений.

Добавление единицы нужно, чтобы значение не было равно нулю.

### Шаг 3. Определение огнедышащей способности

~~~java
boolean fire = kind >= 7;
~~~

Первые семь видов (kind от 0 до 6) не огнедышащие.

Следующие семь (kind от 7 до 13) огнедышащие.

При этом комбинации умений повторяются: kind 0 и kind 7 имеют одинаковую маску abilities, но различаются способностью дышать огнём.

### Шаг 4. Количество голов

~~~java
int heads = between(p.minHeads(), p.maxHeads());
~~~

С помощью between() выбирается случайное целое число в заданном диапазоне включительно.

### Шаг 5. Массив мощности голов

~~~java
int[] power = fire
        ? random.ints(heads, p.minPower(), p.maxPower() + 1).toArray()
        : new int[heads];
~~~

Если дракон огнедышащий:

- random.ints() создаёт поток случайных целых чисел;
- heads задаёт количество чисел;
- minPower — нижняя граница;
- maxPower + 1 — верхняя исключающая граница;
- toArray() собирает числа в массив int[].

Прибавление единицы необходимо, потому что верхняя граница метода Random.ints() не включается в диапазон.

Если дракон не огнедышащий, создаётся массив new int[heads]. Все его элементы автоматически равны нулю.

### Шаг 6. Создание Dragon

~~~java
return new Dragon(
        String.format("Dragon-%03d", index + 1),
        abilities,
        between(p.minSpeed(), p.maxSpeed()),
        between(p.minSpeed(), p.maxSpeed()),
        between(p.minSpeed(), p.maxSpeed()),
        fire,
        power
);
~~~

Создаётся объект Dragon.

String.format("Dragon-%03d", index + 1) формирует имя с тремя цифрами. Например: Dragon-001, Dragon-002.

Для каждой из трёх сред отдельно вызывается between(), поэтому скорости генерируются независимо.

Далее в конструктор передаются маска умений, способность дышать огнём и массив мощности голов.

Конструктор Dragon дополнительно устанавливает скорость в ноль для сред, в которых дракон не умеет передвигаться.

## 8. Метод between(int lo, int hi)

~~~java
private int between(int lo, int hi) {
    return lo + random.nextInt(hi - lo + 1);
}
~~~

Возвращает случайное целое число в диапазоне от lo до hi включительно.

Параметры:

- lo — нижняя граница, тип int;
- hi — верхняя граница, тип int.

Random.nextInt(bound) возвращает число от 0 включительно до bound не включительно.

Поэтому используется формула:

~~~java
lo + random.nextInt(hi - lo + 1)
~~~

Например, если lo = 10, hi = 15, выражение random.nextInt(6) может вернуть 0, 1, 2, 3, 4 или 5. После прибавления 10 результат будет находиться в диапазоне 10–15.

## 9. Пример использования

~~~java
DragonGenerator.Params params = new DragonGenerator.Params(
        20,  // количество драконов
        1, 5, // количество голов
        10, 100, // диапазон скоростей
        10, 50 // диапазон мощности голов
);

DragonGenerator generator = new DragonGenerator(42);
List<Dragon> dragons = generator.generate(params);

System.out.println("Создано драконов: " + dragons.size());

dragons.forEach(System.out::println);
~~~

При одинаковых параметрах и seed генератор позволяет повторять эксперимент с той же последовательностью результатов.

## 10. Важные замечания

- При count = 0 возвращается пустой список.
- Распределение по 14 видам выполняется до перемешивания.
- При количестве драконов, не кратном 14, некоторые виды будут встречаться на один раз чаще остальных.
- После Collections.shuffle() порядок видов в списке становится случайным.
- Генератор не проверяет p на null. При передаче null возникнет NullPointerException.
- Генератор использует параметры Params, а их допустимость проверяется при создании записи.
