# Dragon — модель дракона

[Исходный файл Dragon.java](../Dragon.java)

## 1. Назначение класса

Класс **Dragon** описывает одного дракона и хранит все его характеристики:

- имя;
- набор доступных способов передвижения;
- скорость передвижения по суше, в воздухе и в воде;
- способность дышать огнём;
- количество голов и мощность каждой головы.

Класс также предоставляет методы для получения характеристик и вычисления суммарной, средней, минимальной и максимальной огневой мощности.

Объекты Dragon используются генератором DragonGenerator и всеми заданиями из DragonTasks.

## 2. Константы и битовая маска умений

В классе объявлены три публичные статические константы типа int:

~~~java
public static final int LAND = 1;
public static final int FLY = 2;
public static final int SWIM = 4;
~~~

Каждая константа соответствует отдельному биту двоичного числа:

| Константа | Десятичное значение | Двоичный вид | Значение |
|---|---:|---:|---|
| LAND | 1 | 001 | Передвижение по суше |
| FLY | 2 | 010 | Полёт |
| SWIM | 4 | 100 | Плавание |

Благодаря этому несколько умений можно хранить в одной переменной типа int. Для объединения используется побитовая операция OR — оператор |.

Например:

~~~java
int abilities = Dragon.LAND | Dragon.FLY;
~~~

Получается число 3 (двоичное 011): дракон умеет ходить и летать.

Возможные корректные комбинации:

| Умения | Выражение | Значение |
|---|---|---:|
| Только суша | LAND | 1 |
| Только воздух | FLY | 2 |
| Только вода | SWIM | 4 |
| Суша и воздух | LAND \| FLY | 3 |
| Суша и вода | LAND \| SWIM | 5 |
| Воздух и вода | FLY \| SWIM | 6 |
| Все три умения | LAND \| FLY \| SWIM | 7 |

Проверка конкретного умения выполняется побитовой операцией AND — оператор &:

~~~java
(abilities & LAND) != 0
~~~

Если соответствующий бит установлен, результат AND будет ненулевым. Если бит не установлен, результат будет равен нулю.

## 3. Поля класса

Все поля объявлены как private final. Это означает, что к ним нельзя напрямую обратиться из другого класса, а после присваивания в конструкторе их нельзя переназначить.

| Поле | Тип | Назначение |
|---|---|---|
| name | String | Имя дракона |
| abilities | int | Битовая маска умений |
| landSpeed | int | Скорость передвижения по суше |
| flySpeed | int | Скорость полёта |
| swimSpeed | int | Скорость плавания |
| fireBreathing | boolean | Может ли дракон дышать огнём |
| headPower | int[] | Массив мощности каждой головы |

### Почему headPower имеет тип int[]?

У разных драконов может быть разное количество голов. Поэтому для хранения мощности используется массив целых чисел.

Например:

~~~java
int[] power = {20, 50, 35};
~~~

Это означает, что у дракона три головы с мощностью 20, 50 и 35.

Количество голов определяется длиной массива: headPower.length.

У не огнедышащего дракона массив тоже существует, но все его элементы равны нулю. Благодаря этому методы вычисления мощности не должны каждый раз отдельно проверять способность дышать огнём.

## 4. Конструктор Dragon

~~~java
public Dragon(String name, int abilities, int landSpeed, int flySpeed, int swimSpeed,
              boolean fireBreathing, int[] headPower)
~~~

Конструктор создаёт объект Dragon и принимает семь параметров:

| Параметр | Тип | Описание |
|---|---|---|
| name | String | Имя создаваемого дракона |
| abilities | int | Битовая маска доступных умений |
| landSpeed | int | Скорость по суше |
| flySpeed | int | Скорость в воздухе |
| swimSpeed | int | Скорость в воде |
| fireBreathing | boolean | Признак огнедышащего дракона |
| headPower | int[] | Массив мощности голов |

### Порядок выполнения конструктора

1. Проверяется значение abilities. Оно должно находиться в диапазоне от 1 до 7. Значение 0 означает, что у дракона нет ни одного умения, а значения за пределами 1–7 не соответствуют допустимым комбинациям трёх битов. При нарушении условия выбрасывается IllegalArgumentException.
2. Проверяется длина массива headPower. Она должна быть не меньше 1, то есть у дракона должна быть хотя бы одна голова. Иначе выбрасывается IllegalArgumentException.
3. Имя и маска умений записываются в соответствующие поля объекта.
4. Для каждой среды проверяется наличие умения с помощью побитовой операции &.
5. Если умение отсутствует, скорость в соответствующей среде принудительно устанавливается в 0. Например, дракон без способности плавать получает swimSpeed = 0 независимо от переданного аргумента.
6. Сохраняется значение fireBreathing.
7. Если дракон огнедышащий, массив мощности копируется методом clone(). Если не огнедышащий — создаётся новый массив той же длины, заполненный нулями.

### Зачем используется clone()?

~~~java
this.headPower = fireBreathing ? headPower.clone() : new int[headPower.length];
~~~

Это тернарный оператор: условие ? значение_если_истина : значение_если_ложь.

Метод clone() создаёт копию массива. Поэтому последующее изменение исходного массива в вызывающем коде не изменит сохранённую мощность голов дракона.

В ветке для не огнедышащего дракона оператор new int[headPower.length] создаёт новый массив указанной длины. Элементы массива int по умолчанию равны нулю.

## 5. Методы получения характеристик

Эти методы не изменяют объект, а возвращают значения его полей.

| Метод | Возвращаемый тип | Что возвращает |
|---|---|---|
| name() | String | Имя дракона |
| abilities() | int | Битовую маску умений |
| canLand() | boolean | Может ли передвигаться по суше |
| canFly() | boolean | Может ли летать |
| canSwim() | boolean | Может ли плавать |
| landSpeed() | int | Скорость на суше |
| flySpeed() | int | Скорость в воздухе |
| swimSpeed() | int | Скорость в воде |
| isFireBreathing() | boolean | Способен ли дышать огнём |
| heads() | int | Количество голов |

### canLand(), canFly(), canSwim()

Каждый из этих методов проверяет соответствующий бит маски abilities.

Например:

~~~java
public boolean canFly() {
    return (abilities & FLY) != 0;
}
~~~

Если бит FLY установлен, метод возвращает true, иначе false.

## 6. Работа с мощностью голов

### headPowers()

~~~java
public IntStream headPowers() {
    return Arrays.stream(headPower);
}
~~~

Возвращает поток IntStream, построенный на основе массива headPower.

IntStream — специализированный поток примитивных значений типа int. Он позволяет выполнять операции над числами без преобразования каждого элемента в объект Integer.

Для создания потока используется Arrays.stream().

Например:

~~~java
dragon.headPowers().sum();
~~~

Вычисляет сумму значений массива.

Важно: поток можно использовать только для одной терминальной операции. Если нужны несколько вычислений, следует повторно вызвать headPowers().

### totalPower()

~~~java
public int totalPower() {
    return headPowers().sum();
}
~~~

Возвращает суммарную мощность всех голов.

- Входные параметры: отсутствуют.
- Возвращаемый тип: int.
- Внутри создаётся IntStream и вызывается sum().
- Если все значения равны нулю, результат равен нулю.

### avgPower()

~~~java
public double avgPower() {
    return headPowers().average().orElse(0);
}
~~~

Возвращает среднюю мощность голов.

- Входные параметры: отсутствуют.
- Возвращаемый тип: double.
- average() вычисляет среднее арифметическое и возвращает OptionalDouble.
- orElse(0) возвращает 0, если среднее значение отсутствует.

В текущем классе массив всегда содержит хотя бы один элемент, поэтому отсутствие среднего значения не ожидается при корректном создании объекта. orElse(0) дополнительно задаёт безопасное значение по умолчанию.

### maxHeadPower()

~~~java
public int maxHeadPower() {
    return headPowers().max().orElse(0);
}
~~~

Возвращает максимальную мощность среди всех голов.

- Возвращаемый тип: int.
- max() ищет максимальный элемент потока и возвращает OptionalInt.
- orElse(0) задаёт значение, если поток пустой.

### minHeadPower()

~~~java
public int minHeadPower() {
    return headPowers().min().orElse(0);
}
~~~

Возвращает минимальную мощность среди всех голов. Принцип работы аналогичен maxHeadPower(), но используется min().

### powerSpread()

~~~java
public int powerSpread() {
    return maxHeadPower() - minHeadPower();
}
~~~

Вычисляет разницу между максимальной и минимальной мощностью голов.

Например, если мощности равны 20, 50 и 35:

- максимальная мощность — 50;
- минимальная мощность — 20;
- разность — 30.

## 7. Метод describe(int mask)

~~~java
public static String describe(int mask)
~~~

Статический метод, который преобразует битовую маску в текстовое описание умений.

- Параметр mask: int — битовая маска умений.
- Возвращаемый тип: String.

Пошаговая работа:

1. Stream.of() создаёт поток из трёх строковых выражений.
2. Для каждого умения выполняется проверка соответствующего бита.
3. Если умение присутствует, в поток попадает название: LAND, FLY или SWIM.
4. Если умение отсутствует, вместо названия помещается null.
5. filter(s -> s != null) удаляет null.
6. reduce((a, b) -> a + "+" + b) объединяет оставшиеся строки через знак +.
7. orElse("NONE") возвращает NONE, если объединять нечего.

Пример:

~~~java
Dragon.describe(3); // LAND+FLY
Dragon.describe(4); // SWIM
Dragon.describe(7); // LAND+FLY+SWIM
~~~

Метод static вызывается через имя класса и не требует создания объекта Dragon.

## 8. Метод toString()

Переопределяет стандартный метод Object.toString().

~~~java
@Override
public String toString()
~~~

Возвращает строковое представление дракона с его основными характеристиками.

Используется String.format() — метод форматирования строки.

Спецификаторы формата:

| Спецификатор | Тип данных | Значение |
|---|---|---|
| %s | Строка | Имя, умения, yes/no |
| %d | Целое число | Скорости и количество голов |
| %s | Строка | Массив мощности после Arrays.toString() |

Arrays.toString(headPower) преобразует массив в удобную строку, например [20, 50, 35].

Метод автоматически вызывается при печати объекта через System.out.println(dragon), а также при конкатенации объекта со строкой.

## 9. Пример использования

~~~java
int[] powers = {20, 50, 35};

Dragon dragon = new Dragon(
        "FireDragon",
        Dragon.LAND | Dragon.FLY,
        30, 80, 0,
        true,
        powers
);

System.out.println(dragon.name());
System.out.println(dragon.canFly());
System.out.println(dragon.totalPower());
System.out.println(dragon.avgPower());
System.out.println(dragon);
~~~

Здесь создаётся огнедышащий дракон с тремя головами, который умеет ходить и летать. Скорость плавания будет равна нулю.

## 10. Важные замечания о текущей реализации

- Конструктор проверяет допустимость маски умений и наличие хотя бы одной головы.
- Конструктор не проверяет name на null, не проверяет массив headPower на null и не проверяет неотрицательность скоростей и мощностей.
- Поле headPower защищено от изменения через исходный массив при создании огнедышащего дракона благодаря clone().
- Метод headPowers() возвращает поток, а не сам массив, поэтому вызывающий код не получает прямой доступ к внутреннему массиву.
- У не огнедышащего дракона мощность каждой головы равна нулю независимо от переданного массива.
