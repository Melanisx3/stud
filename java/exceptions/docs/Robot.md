# Robot.java — исполнитель и его координаты

## Назначение класса

`Robot` представляет исполнителя, который перемещается по координатной плоскости.

Класс отвечает только за состояние исполнителя и изменение координат. Он не знает:
- из какого файла пришла команда;
- правильно ли написана команда текстом;
- какое значение `K` задано;
- как исправлять ошибки формата.

Эти обязанности распределены между `Main`, `CommandParser` и `CommandReader`.

## Поля класса

### private long x

Текущая координата по горизонтальной оси.

- При движении на восток (`E`) увеличивается.
- При движении на запад (`W`) уменьшается.

### private long y

Текущая координата по вертикальной оси.

- При движении на север (`N`) увеличивается.
- При движении на юг (`S`) уменьшается.

Используется тип `long`, потому что координаты могут быть значительно больше диапазона `int`.

Модификатор `private` запрещает напрямую менять координаты из других классов. Изменение состояния выполняется через метод `move()`.

## Конструктор Robot(long x, long y)

**Назначение:** создать исполнителя в заданной точке.

**Параметры:**
- `x` — начальная координата по горизонтали;
- `y` — начальная координата по вертикали.

**Возвращаемое значение:** конструкторы не возвращают значение; создаётся новый объект `Robot`.

**Внутри:** параметры записываются в поля объекта:
- `this.x = x`;
- `this.y = y`.

Ключевое слово `this` означает текущий объект. Оно позволяет отличить поле объекта от одноимённого параметра конструктора.

## Метод move(char direction, int distance)

**Назначение:** переместить исполнителя на заданное количество шагов в одном из четырёх направлений.

**Параметры:**
- `direction` — символ направления: `N`, `S`, `E` или `W`;
- `distance` — расстояние перемещения. В нормальном потоке выполнения сюда попадает положительное число, уже проверенное парсером.

**Возвращаемое значение:** отсутствует (`void`). Метод изменяет поля `x` или `y` текущего объекта.

**Может выбросить:**
- `CoordinateOverflowException` — результат изменения координаты выходит за диапазон типа `long`;
- `IllegalArgumentException` — передано неизвестное направление. В штатной работе это предотвращается проверкой парсера.

### Что происходит внутри

Метод использует конструкцию `try-catch` и оператор `switch`.

| Направление | Операция | Результат |
|---|---|---|
| `N` | `y = Math.addExact(y, distance)` | Увеличить `y` |
| `S` | `y = Math.subtractExact(y, distance)` | Уменьшить `y` |
| `E` | `x = Math.addExact(x, distance)` | Увеличить `x` |
| `W` | `x = Math.subtractExact(x, distance)` | Уменьшить `x` |

### Почему используется Math.addExact() и Math.subtractExact()

Обычные арифметические операции над целыми типами Java могут привести к переполнению: значение выйдет за допустимый диапазон, а результат «перепрыгнет» на противоположную сторону диапазона.

Методы `Math.addExact()` и `Math.subtractExact()` проверяют переполнение. Если оно произошло, они выбрасывают `ArithmeticException`.

В блоке `catch` это низкоуровневое исключение преобразуется в более понятное для предметной области `CoordinateOverflowException`. В сообщение включаются направление и расстояние команды.

Если передано неизвестное направление, выполняется ветка `default`, которая выбрасывает `IllegalArgumentException`.

## Метод position()

**Назначение:** получить текстовое представление текущих координат.

**Параметры:** отсутствуют.

**Возвращает:** строку формата `(x, y)`.

Например, если `x = -4`, а `y = 8`, результатом будет строка:

```text
(-4, 8)
```

Метод не меняет состояние робота. Он только формирует строку из текущих значений полей.

## Пример работы

Пусть исполнитель создан так:

```java
Robot robot = new Robot(0, 0);
```

Затем выполняются вызовы:

```java
robot.move('N', 3); // (0, 3)
robot.move('E', 2); // (2, 3)
robot.move('S', 1); // (2, 2)
```

После трёх перемещений `robot.position()` вернёт `(2, 2)`.

## Роль Robot в общей архитектуре

Парсер отвечает за смысл команды и допустимость её параметров. Робот не должен повторно анализировать текст или самостоятельно исправлять команды. Он получает уже проверенные значения и выполняет арифметическое изменение координат.

Такое разделение делает класс `Robot` независимым от формата входного файла и позволяет использовать его с другим источником команд.
