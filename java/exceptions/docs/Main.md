# Main.java — точка входа программы

## Назначение класса

`Main` — главный класс приложения. Его задача — организовать запуск программы:

1. определить имена входного и выходного файлов;
2. открыть потоки чтения и записи;
3. получить из входного файла ограничение `K` и начальные координаты;
4. создать исполнителя, парсер и читатель;
5. запустить обработку команд;
6. записать итоговую позицию;
7. обработать ошибки, связанные с заголовком и файлами.

Класс не разбирает отдельные команды перемещения. Этим занимается `CommandParser`.

## Импорты

- `BufferedReader` — буферизированное чтение текста построчно.
- `BufferedWriter` — буферизированная запись текста.
- `IOException` — базовое исключение операций ввода-вывода.
- `StandardCharsets` — набор кодировок; используется UTF-8.
- `AccessDeniedException` — ошибка отсутствия доступа к файлу.
- `NoSuchFileException` — файл не найден.
- `Files` — утилитные методы для работы с файлами и потоками.
- `Paths` — преобразование строкового пути в объект пути.

## Метод main(String[] args)

**Назначение:** начальная точка выполнения Java-программы.

**Параметр:**
- `args` — массив аргументов командной строки. `args[0]`, если он передан, задаёт входной файл; `args[1]` задаёт выходной файл.

**Возвращаемое значение:** отсутствует (`void`).

### Что происходит внутри

1. Выбирается имя входного файла:
   - если передан первый аргумент — используется он;
   - иначе используется `commands.txt`.

2. Выбирается имя выходного файла:
   - если передан второй аргумент — используется он;
   - иначе используется `result.txt`.

3. Открываются два ресурса в конструкции `try-with-resources`:
   - `BufferedReader in` для входного файла;
   - `BufferedWriter out` для результирующего файла.

   Конструкция `try-with-resources` автоматически закрывает потоки после выхода из блока, в том числе если возникает исключение.

4. Вызывается `readK(in)`, чтобы получить допустимый предел длины перемещения.

5. Вызывается `readStart(in)`, чтобы получить координаты `x` и `y`.

6. Создаётся объект `Robot` с начальными координатами.

7. Создаётся `CommandParser`, которому передаются `K` и ссылка на робота.

8. Создаётся `CommandReader`, которому передаются парсер, робот и поток записи отчёта.

9. В результирующий файл записываются `K` и начальная позиция.

10. Вызывается `reader.readAll(in, 2)`. Число 2 означает, что две строки заголовка уже прочитаны; следующая строка будет иметь номер 3.

11. После обработки всех команд записывается итоговая позиция.

12. В консоль выводится сообщение об успешном завершении.

### Обработка исключений

- `NoSuchFileException` — входной файл не найден (либо путь не существует). Выводится путь к файлу.
- `AccessDeniedException` — нет прав на доступ к файлу.
- `InvalidHeaderException` — некорректны `K` или начальные координаты.
- `IOException` — прочие ошибки чтения или записи.

Порядок обработчиков важен: более конкретные исключения должны идти раньше общего `IOException`.

## Метод readK(BufferedReader in)

**Назначение:** прочитать и проверить значение ограничения `K` из первой строки файла.

**Параметр:**
- `in` — поток чтения входного файла.

**Возвращает:** положительное значение `K` типа `int`.

**Может выбросить:**
- `IOException` — ошибка чтения;
- `InvalidHeaderException` — строка отсутствует, не является целым числом или содержит неположительное значение.

### Последовательность действий

1. Вызывается `in.readLine()`, читается первая строка.
2. Если результат равен `null`, файл закончился до появления `K`. Генерируется `InvalidHeaderException`.
3. Строка очищается от пробелов по краям с помощью `trim()`.
4. `Integer.parseInt()` пытается преобразовать строку в `int`.
5. Если число меньше или равно нулю, генерируется `InvalidHeaderException`.
6. Если преобразование успешно и число положительное, оно возвращается.
7. Если `parseInt()` выбросил `NumberFormatException`, исключение преобразуется в `InvalidHeaderException` с пояснением о некорректном значении `K`.

## Метод readStart(BufferedReader in)

**Назначение:** прочитать начальные координаты исполнителя из второй строки файла.

**Параметр:**
- `in` — поток чтения входного файла.

**Возвращает:** массив `long[]` из двух элементов:
- индекс 0 — координата `x`;
- индекс 1 — координата `y`.

**Может выбросить:**
- `IOException` — ошибка чтения;
- `InvalidHeaderException` — отсутствуют координаты, их количество не равно двум или значения не помещаются в `long`/не являются целыми числами.

### Последовательность действий

1. Считывается следующая строка.
2. Если файл закончился, генерируется исключение об отсутствии начальных координат.
3. Строка очищается по краям методом `trim()`.
4. Метод `split("\\s+")` делит строку по одному или нескольким пробельным символам.
5. Проверяется, что получилось ровно два элемента.
6. Оба элемента преобразуются через `Long.parseLong()`.
7. Создаётся массив `new long[] {x, y}` и возвращается вызывающему коду.
8. Если хотя бы одно значение не удалось преобразовать, `NumberFormatException` заменяется на `InvalidHeaderException`.

## Пример входного заголовка

```text
15
-4 8
N 3
E 2
Q
```

После выполнения `readK()` переменная `k` равна 15. После выполнения `readStart()` массив содержит `[-4, 8]`. Затем создаётся робот в точке `(-4, 8)`.

## Почему заголовок обрабатывается в Main

Заголовок определяет параметры всей программы, а не отдельной команды. Без корректного `K` парсер не сможет проверить допустимое расстояние; без координат нельзя создать исполнителя. Поэтому ошибки заголовка обрабатываются до создания `CommandReader` и не передаются в цикл исправления команд.
