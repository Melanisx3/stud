## Назначение программы

Программа читает текстовый файл с параметром ограничения шага `K`, начальными координатами робота и командами перемещения. Для каждой команды она пытается выполнить разбор и перемещение. Если строка содержит ошибку, парсер выбрасывает соответствующее исключение. Читатель перехватывает его и либо исправляет строку, возвращая её на повторную обработку, либо записывает сообщение о невозможности выполнения.

Результат обработки и итоговые координаты записываются в выходной файл.

## Структура входного файла

Ожидаемый формат:

```text
K
x y
команда 1
команда 2
...
X
```

- Первая строка — положительное целое число `K`.
- Вторая строка — две целочисленные координаты `x y`.
- Далее идут команды, по одной на строку.
- Строка `X` или `Q` завершает список команд. Завершитель необязателен: допустим конец файла.

Пример:

```text
10
0 0
N 3
E 2
S -1
nn 2
X
```
