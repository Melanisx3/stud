# Лабораторная работа №3
## Ответы на контрольные вопросы (пункт 3.6)

### 1. В чём отличие библиотечных функций языков программирования от библиотечных функций СУБД и в чём их общность?

Библиотечные функции языков программирования выполняются программой в среде соответствующего языка и предназначены для обработки данных и выполнения различных операций внутри программы.

Библиотечные функции СУБД выполняются непосредственно системой управления базами данных. Они предназначены для обработки данных, хранящихся в базе, преобразования значений, вычислений, форматирования и получения результатов SQL-запросов.

**Общность:** и те и другие представляют собой заранее реализованные средства, которые позволяют повторно использовать готовые алгоритмы и не писать их самостоятельно каждый раз.

**Отличие:** функции языка программирования вызываются из программного кода, а функции СУБД используются в SQL-запросах и выполняются на стороне базы данных.

### 2. Дайте понятие строковой функции.

Строковая функция — это встроенная функция СУБД, предназначенная для обработки текстовых данных.

Она позволяет объединять строки, изменять регистр символов, определять длину строки, извлекать подстроки, заменять символы и удалять лишние пробелы.

Примеры строковых функций PostgreSQL:

- `UPPER()` — переводит строку в верхний регистр.
- `LOWER()` — переводит строку в нижний регистр.
- `INITCAP()` — делает первую букву каждого слова заглавной.
- `CONCAT()` — объединяет строки.
- `LENGTH()` — определяет количество символов.
- `SUBSTRING()` — извлекает часть строки.
- `REPLACE()` — заменяет вхождения одной подстроки другой.
- `REVERSE()` — записывает символы строки в обратном порядке.

### 3. Дайте понятие агрегатной функции (функции группирования).

Агрегатная функция — это функция СУБД, которая выполняет вычисления над набором строк и возвращает одно итоговое значение для всего набора или для каждой группы строк.

Агрегатные функции используются для получения сводной информации из таблиц. Обычно они применяются совместно с предложением `GROUP BY`, а для фильтрации сформированных групп используется `HAVING`.

Примеры:

- `COUNT()` — подсчитывает количество строк.
- `SUM()` — вычисляет сумму значений.
- `AVG()` — вычисляет среднее значение.
- `MIN()` — находит минимальное значение.
- `MAX()` — находит максимальное значение.

### 4. Какие строковые функции могут понадобиться для создания табличного отчёта со столбцом «Фамилия И.О.»?

Для формирования такого столбца могут понадобиться следующие функции:

- `INITCAP()` — для приведения фамилии и имени к нужному регистру.
- `LEFT()` или `SUBSTRING()` — для извлечения первой буквы имени и отчества.
- `CONCAT()` или оператор `||` — для объединения фамилии, инициалов и точек.

Пример:

```sql
SELECT
    CONCAT(
        INITCAP(last_name), ' ',
        LEFT(INITCAP(first_name), 1), '. ',
        LEFT(INITCAP(middle_name), 1), '.'
    ) AS "Фамилия И.О."
FROM customer_maksimova;
```

Результат будет выглядеть следующим образом: `Орлов А. В.`

### 5. Для решения каких задач форматирования нужно использовать функцию format?

Функция `format()` в PostgreSQL используется для формирования текстовых строк по заданному шаблону.

Она позволяет:
- объединять текст и значения разных типов;
- задавать минимальную ширину поля;
- выравнивать значения по левому или правому краю;
- подставлять аргументы в определённые позиции;
- безопасно формировать SQL-идентификаторы и строковые литералы с помощью специальных спецификаторов.

Основные спецификаторы:

- `%s` — обычная строка;
- `%I` — SQL-идентификатор;
- `%L` — SQL-литерал;
- `%%` — символ `%`.

Пример:

```sql
SELECT format(
    'Клиент: %s, телефон: %s',
    'Иванов',
    '+7-900-123-45-67'
);
```

Результат: `Клиент: Иванов, телефон: +7-900-123-45-67`.

### 6. Для решения каких задач форматирования нужно использовать функцию formatstr?

В задании указано название `formatstr`. Однако в рассматриваемом материале лабораторной работы описана функция PostgreSQL `format()`, а не отдельная встроенная функция `formatstr()`.

Вероятнее всего, имеется в виду строка формата (`formatstr`) — первый аргумент функции `format()`. Она задаёт шаблон, по которому формируется итоговая строка.

Строка формата позволяет определить:
- расположение подставляемых значений;
- тип преобразования аргументов;
- ширину поля;
- выравнивание результата;
- порядок использования аргументов.

Пример:

```sql
SELECT format('|%-10s|', 'Иванов');
```

Результат: `|Иванов    |`.

Таким образом, `formatstr` — это не самостоятельная функция, а строка-шаблон, используемая функцией `format()`.

### 7. Приведите пример математических функций SQL, которые Вы не встречали ни в одном из ЯП!

Примеры математических функций PostgreSQL:

- `GCD(a, b)` — вычисляет наибольший общий делитель двух чисел.
- `LCM(a, b)` — вычисляет наименьшее общее кратное двух чисел.
- `FACTORIAL(n)` — вычисляет факториал числа.
- `DIV(y, x)` — возвращает целочисленный результат деления.
- `TRIM_SCALE(numeric)` — удаляет конечные нули в дробной части числа.

Примеры:

```sql
SELECT GCD(1071, 462);
SELECT LCM(1071, 462);
SELECT FACTORIAL(5);
SELECT DIV(9, 4);
SELECT TRIM_SCALE(8.4100);
```

Результаты соответственно: `21`, `23562`, `120`, `2`, `8.41`.

Эти функции демонстрируют дополнительные возможности математической библиотеки PostgreSQL. При этом некоторые из них могут встречаться и в отдельных языках программирования или их библиотеках.

### 8. Какие функции для работы с датами могут понадобиться для создания табличного отчёта со столбцом «Дата рождения»?

Для формирования отчёта могут понадобиться:

- `TO_CHAR()` — для отображения даты в нужном формате;
- `EXTRACT()` — для извлечения дня, месяца или года;
- `AGE()` — для вычисления возраста на основании даты рождения и текущей даты;
- `CURRENT_DATE` — для получения текущей даты.

Пример:

```sql
SELECT
    TO_CHAR(birth_date, 'DD.MM.YYYY') AS "Дата рождения",
    EXTRACT(YEAR FROM AGE(CURRENT_DATE, birth_date)) AS age
FROM customers;
```

Здесь `TO_CHAR()` форматирует дату, а `AGE()` и `EXTRACT()` позволяют определить возраст человека в полных годах.

### 9. Какие функции для работы с датами могут понадобиться для программирования ПЕРВОЙ даты каждого месяца?

Для определения первого дня месяца можно использовать:

- `DATE_TRUNC('month', date)` — округляет дату до начала месяца;
- `MAKE_DATE(year, month, day)` — создаёт дату из отдельных значений года, месяца и дня;
- `EXTRACT()` — извлекает год и месяц из исходной даты.

Пример первого способа:

```sql
SELECT DATE_TRUNC('month', CURRENT_DATE)::DATE;
```

Пример второго способа:

```sql
SELECT MAKE_DATE(
    EXTRACT(YEAR FROM CURRENT_DATE)::INTEGER,
    EXTRACT(MONTH FROM CURRENT_DATE)::INTEGER,
    1
);
```

Оба запроса возвращают первое число текущего месяца.

### 10. Как задать формат даты, который используется в России?

Для отображения даты в распространённом российском формате используется функция `TO_CHAR()` с шаблоном `DD.MM.YYYY`.

Пример:

```sql
SELECT TO_CHAR(CURRENT_DATE, 'DD.MM.YYYY');
```

Результат будет иметь вид `27.11.2026`.

Также можно установить порядок представления даты при вводе и выводе с помощью:

```sql
SET DATESTYLE TO 'German, DMY';
```

Параметр `DMY` означает день, месяц, год.

Для форматирования конкретного значения в отчёте предпочтительно использовать `TO_CHAR()`.

### 11. Для чего нужно использовать оператор OVERLAPS?

Оператор `OVERLAPS` используется для проверки пересечения двух временных интервалов.

Он позволяет определить, имеют ли два периода хотя бы одну общую часть времени.

Оператор применяется при работе с датами, временем и временными интервалами.

Пример:

```sql
SELECT
    (DATE '2026-10-01', DATE '2026-10-15')
    OVERLAPS
    (DATE '2026-10-10', DATE '2026-10-20')
    AS periods_overlap;
```

Результат: `TRUE`, поскольку временные интервалы пересекаются.

В базе данных аренды недвижимости этот оператор может использоваться для проверки, не пересекаются ли сроки действия договоров аренды одного объекта.

### 12. Почему в SQL и программировании на языках диалектов нельзя обойтись без функций преобразования (приведения) типов?

Функции преобразования типов необходимы, поскольку разные типы данных предназначены для хранения и обработки разных значений и не всегда могут использоваться совместно.

Преобразование типов позволяет:
- выполнять арифметические операции над значениями подходящих типов;
- сравнивать данные разных типов;
- преобразовывать текст в числа и даты;
- получать текстовое представление числовых и временных значений;
- обеспечивать совместимость данных при выполнении запросов.

В PostgreSQL для преобразования типов используются `CAST()` и оператор `::`.

Примеры:

```sql
SELECT CAST('123' AS INTEGER);

SELECT '2026-11-27'::DATE;

SELECT CAST(1500 AS TEXT);
```

Таким образом, преобразование типов обеспечивает корректную обработку данных и совместимость различных типов при выполнении SQL-запросов.

### 13. Перечислите наиболее часто используемые агрегатные (групповые) функции.

Наиболее часто используемые агрегатные функции:

- `COUNT()` — подсчёт количества строк или значений;
- `SUM()` — вычисление суммы;
- `AVG()` — вычисление среднего арифметического;
- `MIN()` — поиск минимального значения;
- `MAX()` — поиск максимального значения.

Они применяются для получения сводных результатов по таблице или отдельным группам записей.

### 14. Какая связь между предложением GROUP BY и агрегатными функциями?

`GROUP BY` используется совместно с агрегатными функциями для разделения строк таблицы на группы по значениям одного или нескольких столбцов.

После группировки агрегатная функция выполняет вычисления отдельно для каждой группы и возвращает одну итоговую строку на группу.

Пример:

```sql
SELECT
    realtor_id,
    COUNT(*) AS contracts_count
FROM contract_maksimova
GROUP BY realtor_id;
```

Запрос группирует договоры по риэлторам и подсчитывает количество договоров каждого риэлтора.

Если в `SELECT` используется обычный столбец, не являющийся аргументом агрегатной функции, он, как правило, должен присутствовать в `GROUP BY`.

### 15. Какая связь между предложением HAVING и агрегатными функциями?

`HAVING` используется для фильтрации уже сформированных групп по результатам агрегатных вычислений.

В отличие от `WHERE`, которое фильтрует отдельные строки до группировки, `HAVING` проверяет условие для каждой сформированной группы.

Пример:

```sql
SELECT
    realtor_id,
    COUNT(*) AS contracts_count
FROM contract_maksimova
GROUP BY realtor_id
HAVING COUNT(*) > 1;
```

Запрос выводит только тех риэлторов, у которых количество договоров больше одного.

Таким образом:

- `WHERE` — фильтрация строк до группировки;
- `GROUP BY` — формирование групп;
- `HAVING` — фильтрация сформированных групп по агрегатным условиям.
