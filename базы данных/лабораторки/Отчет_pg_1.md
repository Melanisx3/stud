# Отчёт по базе данных «Аренда недвижимости»

**СУБД:** PostgreSQL  
**Название базы данных:** `real_estate_rental`  
**Пользователь:** `rental_user`

---

## 1. Описание реляционных отношений

База данных «Аренда недвижимости» предназначена для хранения и обработки информации о риэлторах, клиентах, типах недвижимости, районах, сроках аренды, объектах недвижимости, стоимости аренды и договорах.

База данных состоит из восьми реляционных отношений (таблиц), связанных между собой первичными и внешними ключами.

Первичный ключ (PK) обеспечивает уникальную идентификацию каждой записи таблицы. Внешний ключ (FK) устанавливает связь между таблицами и обеспечивает ссылочную целостность данных.

### 1.1. Таблица `realtor_maksimova` — Риэлтор

Таблица предназначена для хранения информации о риэлторах, работающих с клиентами и сопровождающих договоры аренды недвижимости.

**Атрибуты:**

| Атрибут | Тип данных | Назначение |
|---|---|---|
| id | smallint | Уникальный идентификатор риэлтора |
| last_name | varchar | Фамилия риэлтора |
| first_name | varchar | Имя риэлтора |
| middle_name | varchar | Отчество риэлтора |
| phone | char | Номер телефона |
| email | varchar | Адрес электронной почты |

**Первичный ключ:** `id`.

**Внешние ключи:** отсутствуют.

Связь с таблицей `contract_maksimova` осуществляется через атрибут `realtor_id`. Один риэлтор может сопровождать несколько договоров аренды.

### 1.2. Таблица `customer_maksimova` — Клиент

Таблица предназначена для хранения персональных и контактных данных клиентов, заключающих договоры аренды недвижимости.

**Атрибуты:**

| Атрибут | Тип данных | Назначение |
|---|---|---|
| id | smallint | Уникальный идентификатор клиента |
| last_name | varchar | Фамилия клиента |
| first_name | varchar | Имя клиента |
| middle_name | varchar | Отчество клиента |
| passport_series | varchar | Серия паспорта |
| passport_number | varchar | Номер паспорта |
| phone | char | Номер телефона |
| email | varchar | Адрес электронной почты |

**Первичный ключ:** `id`.

**Внешние ключи:** отсутствуют.

Связь с таблицей `contract_maksimova` осуществляется через атрибут `client_id`. Один клиент может заключить несколько договоров аренды.

### 1.3. Таблица `property_type_maksimova` — Тип недвижимости

Таблица представляет собой справочник типов недвижимости, используемых для классификации объектов.

**Атрибуты:**

| Атрибут | Тип данных | Назначение |
|---|---|---|
| id | smallint | Уникальный идентификатор типа недвижимости |
| property_type | varchar | Наименование типа недвижимости |

**Первичный ключ:** `id`.

**Внешние ключи:** отсутствуют.

Связь с таблицей `property_maksimova` осуществляется через атрибут `property_type_id`. Один тип недвижимости может соответствовать нескольким объектам.

### 1.4. Таблица `district_maksimova` — Район

Таблица предназначена для хранения информации о районах города и их рейтингах.

**Атрибуты:**

| Атрибут | Тип данных | Назначение |
|---|---|---|
| id | smallint | Уникальный идентификатор района |
| district_name | varchar | Название района |
| rating | numeric | Рейтинг района |

**Первичный ключ:** `id`.

**Внешние ключи:** отсутствуют.

Связь с таблицей `property_maksimova` осуществляется через атрибут `district_id`. Один район может содержать несколько объектов недвижимости.

### 1.5. Таблица `rental_duration_maksimova` — Срок аренды

Таблица представляет собой справочник вариантов продолжительности аренды недвижимости.

**Атрибуты:**

| Атрибут | Тип данных | Назначение |
|---|---|---|
| id | smallint | Уникальный идентификатор срока аренды |
| rental_duration | varchar | Наименование срока аренды |

**Первичный ключ:** `id`.

**Внешние ключи:** отсутствуют.

Связь с таблицей `price_maksimova` осуществляется через атрибут `rental_duration_id`. Один вариант срока аренды может использоваться в нескольких записях стоимости недвижимости.

### 1.6. Таблица `property_maksimova` — Объект недвижимости

Таблица предназначена для хранения информации об объектах недвижимости, доступных для аренды. Содержит адрес объекта, его тип, район и количество комнат.

**Атрибуты:**

| Атрибут | Тип данных | Назначение |
|---|---|---|
| id | smallint | Уникальный идентификатор объекта |
| property_type_id | smallint | Идентификатор типа недвижимости |
| city | varchar | Город расположения объекта |
| district_id | smallint | Идентификатор района |
| street | varchar | Название улицы |
| house_number | varchar | Номер дома |
| apartment_number | varchar | Номер квартиры |
| room_count | integer | Количество комнат |

**Первичный ключ:** `id`.

**Внешние ключи:**
- `property_type_id` ссылается на `property_type_maksimova(id)`.
- `district_id` ссылается на `district_maksimova(id)`.

Один тип недвижимости может соответствовать нескольким объектам. Аналогично, один район может включать несколько объектов недвижимости.

### 1.7. Таблица `price_maksimova` — Цена

Таблица предназначена для хранения стоимости аренды объектов недвижимости с учётом выбранного срока аренды и даты изменения цены.

**Атрибуты:**

| Атрибут | Тип данных | Назначение |
|---|---|---|
| id | smallint | Уникальный идентификатор цены |
| property_id | smallint | Идентификатор объекта недвижимости |
| price_change_date | date | Дата изменения цены |
| price | numeric | Стоимость аренды |
| rental_duration_id | smallint | Идентификатор срока аренды |

**Первичный ключ:** `id`.

**Внешние ключи:**
- `property_id` ссылается на `property_maksimova(id)`.
- `rental_duration_id` ссылается на `rental_duration_maksimova(id)`.

Один объект недвижимости может иметь несколько записей стоимости. Один вариант срока аренды может использоваться для разных объектов недвижимости.

### 1.8. Таблица `contract_maksimova` — Договор

Таблица предназначена для хранения информации о заключённых договорах аренды недвижимости. Она связывает клиента, риэлтора, объект недвижимости и установленную стоимость аренды.

**Атрибуты:**

| Атрибут | Тип данных | Назначение |
|---|---|---|
| id | smallint | Уникальный идентификатор договора |
| client_id | smallint | Идентификатор клиента |
| realtor_id | smallint | Идентификатор риэлтора |
| property_id | smallint | Идентификатор объекта недвижимости |
| start_date | date | Дата начала аренды |
| end_date | date | Дата окончания аренды |
| price_id | smallint | Идентификатор стоимости аренды |

**Первичный ключ:** `id`.

**Внешние ключи:**
- `client_id` ссылается на `customer_maksimova(id)`.
- `realtor_id` ссылается на `realtor_maksimova(id)`.
- `property_id` ссылается на `property_maksimova(id)`.
- `price_id` ссылается на `price_maksimova(id)`.

Один клиент может заключать несколько договоров. Один риэлтор может сопровождать несколько договоров. Один объект недвижимости и одна запись стоимости также могут быть связаны с несколькими договорами.

## 2. Описание связей между отношениями

Таблицы базы данных связаны между собой с использованием первичных и внешних ключей.

В базе данных реализованы следующие связи типа «один-ко-многим» (1:N):

| № | Первая таблица | Вторая таблица | Условие связи |
|---|---|---|---|
| 1 | realtor_maksimova | contract_maksimova | realtor_maksimova.id = contract_maksimova.realtor_id |
| 2 | customer_maksimova | contract_maksimova | customer_maksimova.id = contract_maksimova.client_id |
| 3 | property_type_maksimova | property_maksimova | property_type_maksimova.id = property_maksimova.property_type_id |
| 4 | district_maksimova | property_maksimova | district_maksimova.id = property_maksimova.district_id |
| 5 | property_maksimova | price_maksimova | property_maksimova.id = price_maksimova.property_id |
| 6 | rental_duration_maksimova | price_maksimova | rental_duration_maksimova.id = price_maksimova.rental_duration_id |
| 7 | property_maksimova | contract_maksimova | property_maksimova.id = contract_maksimova.property_id |
| 8 | price_maksimova | contract_maksimova | price_maksimova.id = contract_maksimova.price_id |

Таким образом, таблицы образуют единую реляционную структуру. Использование внешних ключей позволяет связывать информацию из разных отношений и обеспечивает целостность данных.
