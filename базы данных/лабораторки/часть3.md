## 1. Почему запросы являются важным элементом ИС БД?

Таблицы только **хранят** данные. Чтобы получить из них нужную информацию, нужны запросы.

Роль запросов в ИС:

- **Выборка нужных данных.** Из тысяч записей отбираются только нужные (например, преподаватели кафедры алгебры).
- **Объединение таблиц.** Данные из нескольких таблиц собираются в один результат (ФИО студента + название специальности вместо кода).
- **Вычисления и статистика.** Подсчёт количества, средних значений, сумм (средний балл студента, число преподавателей на кафедре).
- **Основа для форм и отчётов.** Форма или отчёт можно строить не только на таблице, но и на запросе, а значит, показывать уже отобранные и обработанные данные.
- **Гибкость.** Запрос можно изменить и выполнить заново, не трогая сами данные.
- **Безопасность.** Пользователю можно показывать только результат запроса, а не всю таблицу целиком.

**Вывод:** запросы — «мозг» ИС: они превращают хранилище данных в источник информации для принятия решений.

## 2. Какой оператор SQL лежит в основе любого запроса?

Оператор **`SELECT`** (выборка). Любой запрос на выборку в Base, как бы он ни создавался, в итоге превращается в `SELECT`.

Общий вид:

```sql
SELECT   поля или выражения
FROM     таблицы
WHERE    условие отбора строк
GROUP BY поля группировки
HAVING   условие отбора групп
ORDER BY поля сортировки;
```

**Пример:**

```sql
SELECT "ФИО", "Дата_рождения"
FROM "Студент"
WHERE "Пол" = 'Ж'
ORDER BY "ФИО";
```

## 3. Какие три режима LibreOffice Base предлагает для создания запроса?

Раздел **«Запросы»** в левой панели Base, область «Задачи»:

1. **Создать запрос в режиме дизайна…** — вручную в графическом конструкторе: добавляем таблицы, выбираем поля, задаём условия.
2. **Использовать мастер для создания запроса…** — пошаговый мастер (выбор таблицы и полей, сортировка, условия, группировка, псевдонимы).
3. **Создать запрос в режиме SQL…** — вручную пишется текст SQL-запроса.

Дополнительно: в режиме дизайна можно переключиться в SQL-вид кнопкой **«Переключить режим просмотра дизайна»**.

## 4. Расскажите алгоритм создания запроса в режиме дизайна

1. В главном окне Base слева выбрать **«Запросы»**.
2. Нажать **«Создать запрос в режиме дизайна…»**.
3. В окне **«Добавление таблицы или запроса»** выбрать нужные таблицы (кнопка **«Добавить»**), затем **«Закрыть»**.
4. Если таблиц несколько, проверить **связи** между ними. Они появляются автоматически, если заданы в схеме БД. Иначе перетащить поле одной таблицы на соответствующее поле другой.
5. В нижней части окна (**таблица дизайна запроса**) выбрать поля. Способы:
   - двойной клик по полю в таблице вверху;
   - перетаскивание поля в столбец;
   - выбор в строке **«Поле»** из выпадающего списка.
6. При необходимости заполнить строки: **«Псевдоним», «Сортировка», «Видимый», «Функция», «Критерий», «Или»**.
7. Нажать **«Выполнить запрос»** (значок ▶ на панели) и проверить результат.
8. Сохранить запрос (**Ctrl+S**) и ввести имя, например `Запрос_Студентки`.

**Пример:** вывести ФИО студентов и название их специальности.
- Добавить таблицы `Студент` и `Специальность`.
- В строку «Поле» выбрать `Студент.ФИО` и `Специальность.Наименование`.
- Выполнить запрос.

## 5. Нужно ли указывать имена таблиц в строке «Таблица»?

**Нет, вручную вводить не нужно.** Строка «Таблица» заполняется **автоматически** при выборе поля. Она показывает, из какой таблицы это поле.

Нюансы:

- Если в запросе **одна таблица**, строку можно скрыть (*Вид → Функции таблиц*, флажок «Имя таблицы»).
- Если таблиц **несколько**, строка нужна. Одноимённые поля (`ID` есть в разных таблицах) различаются именно по ней.
- Строка «Таблица» нужна и тогда, когда вы меняете поле и хотите выбрать его из другой таблицы запроса.

## 6. Для чего используется строка «Псевдоним»?

**Псевдоним (alias)** — это **имя столбца в результате запроса**, отличное от настоящего имени поля. В SQL это оператор `AS`.

Зачем нужен:

- сделать заголовки понятнее («ФИО» → «Фамилия, имя, отчество»);
- дать имя вычисляемому столбцу или результату групповой функции («COUNT(...)» → «Количество студентов»);
- различить одноимённые поля из разных таблиц (`Кафедра.Наименование` и `Специальность.Наименование`).

**Пример:** в строке «Псевдоним» для `Наименование` из `Кафедра` указать `Кафедра`. В SQL получится:

```sql
SELECT "Кафедра"."Наименование" AS "Кафедра" FROM "Кафедра"
```

Если в псевдониме есть пробелы, LibreOffice заключит его в кавычки автоматически.

## 7. Для чего используется строка «Видимый»?

Флажок **«Видимый»** определяет, **показывать ли поле в результате запроса**.

- ☑ Поле **включено**: столбец выводится в результате.
- ☐ Поле **выключено**: столбец не показывается, но **продолжает участвовать** в запросе (в условии отбора, сортировке).

**Пример:** нужно вывести ФИО студентов-женщин, но столбец «Пол» показывать не нужно.
- Поле `Пол`: Критерий `'Ж'`, «Видимый» **выключен**.
- Поле `ФИО`: «Видимый» **включён**.

В SQL поле остаётся в `WHERE`, но пропадает из `SELECT`.

## 8. Для чего используется строка «Функция»?

В строке **«Функция»** выбирается:

- **групповая (агрегатная) функция**: `Сумма`, `Среднее`, `Количество`, `Минимум`, `Максимум` и др.;
- **«Группировка»**, чтобы сгруппировать записи по значению поля.

Строка «Функция» по умолчанию скрыта. Она появляется после нажатия кнопки **«Функции»** (значок **Σ**) на панели инструментов конструктора запросов (или *Вид → Функции*).

**Пример:** число студентов на каждой специальности.

| Поле | Специальность.Наименование | Студент.Номер_зачетки |
|---|---|---|
| Функция | Группировка | Количество |

Результат: по строке на каждую специальность, рядом число студентов.

---

## 9. Для чего используется строка «Критерий»?

В строке **«Критерий»** задаётся **условие отбора записей**. В результат попадают только строки, удовлетворяющие условию. В SQL это раздел `WHERE` (или `HAVING`, если условие накладывается на групповую функцию).

Примеры значений:

| Критерий | Смысл |
|---|---|
| `'Ж'` | равно «Ж» |
| `>= 4` | больше или равно 4 |
| `LIKE 'Ив%'` | начинается с «Ив» |
| `BETWEEN 3 AND 5` | от 3 до 5 |
| `IS NULL` | значение не задано |
| `<> 'Доцент'` | не равно |

Строка **«Или»** (и следующие) нужна для альтернативных условий.

## 10. Как задать условие выборки?

1. Открыть запрос в режиме дизайна.
2. Выбрать поле, по которому отбираем (например, `Оценка`).
3. В строке **«Критерий»** этого поля ввести условие (например, `>= 4`).
4. Выполнить запрос.

**Несколько условий:**

- **И (AND):** условия в **одной строке «Критерий»** под разными полями. Пример: `Пол` = `'Ж'` и `Специальность` = `'010101'`. Обе строки отбора в одной горизонтали.
- **ИЛИ (OR):** условия в **разных строках** (в «Критерий» и в «Или»). Пример: `Должность` = `'Доцент'` в строке «Критерий», `Должность` = `'Профессор'` в строке «Или».

**Пример в SQL:**

```sql
SELECT "ФИО" FROM "Студент"
WHERE "Пол" = 'Ж' AND "Специальность" = '010101'
```

Текстовые значения пишутся в одинарных кавычках, числа без кавычек. Даты пишутся в формате `'2005-09-01'`.

## 13. Чем запрос с параметрами отличается от «простого» запроса?

| | Простой запрос | Запрос с параметрами |
|---|---|---|
| Условие отбора | Задано **заранее** внутри запроса | **Вводится пользователем** при каждом запуске |
| Гибкость | Для изменения нужно править запрос | Один запрос подходит для разных значений |
| Запуск | Сразу выдаёт результат | Сначала показывает **окно ввода параметра** |

**Пример:**
- простой: `WHERE "Пол" = 'Ж'` всегда выбирает только женщин;
- с параметром: `WHERE "Пол" = :Введите_пол` при запуске спросит «Введите_пол», и результат зависит от ответа.

## 14. Как создать запрос с параметрами?

1. Создать запрос в режиме дизайна (или SQL).
2. В строке **«Критерий»** нужного поля вместо значения ввести **параметр**: двоеточие и имя параметра:

   ```
   :Введите_фамилию
   ```
3. Имя параметра не должно содержать пробелов (вместо них `_`) или должно быть без двоеточия внутри. Оно будет показано пользователю как подсказка.
4. Выполнить запрос. Появится окно **«Ввод параметра»**.
5. Ввести значение и нажать **OK**.

**Пример в SQL:**

```sql
SELECT "ФИО", "Номер_зачетки"
FROM "Студент"
WHERE "Специальность" = :Код_специальности
```

**Несколько параметров:** в нескольких полях можно указать разные параметры, запрос спросит каждый по очереди.

**Числовой диапазон:**

```sql
WHERE "Оценка" BETWEEN :Оценка_от AND :Оценка_до
```

## 15. Для чего используется оператор LIKE в запросе с параметрами?

**`LIKE`** — оператор **сравнения с шаблоном**. Он позволяет искать записи не по точному значению, а по части текста.

Подстановочные символы:

- `%` — любое количество любых символов (в том числе ни одного);
- `_` — ровно один любой символ.

Зачем с параметрами: пользователю не нужно вводить значение полностью, достаточно начала фамилии, фрагмента названия.

**Пример:**

```sql
SELECT "ФИО", "Номер_зачетки"
FROM "Студент"
WHERE "ФИО" LIKE :Введите_начало_фамилии || '%'
```

Пользователь вводит `Ив`, а запрос найдёт «Иванов», «Иванова», «Ивашов» и т. д.

Варианты шаблона:

| Шаблон | Что находит |
|---|---|
| `'Ив%'` | начинается с «Ив» |
| `'%ов'` | заканчивается на «ов» |
| `'%ан%'` | содержит «ан» |
| `'П_тров'` | «Петров», «Потров» |

Для поиска без учёта регистра можно использовать `LOWER("ФИО") LIKE LOWER(:Параметр) || '%'`.

## 16. Какие групповые функции использует LibreOffice Base? Опишите их

Групповые (агрегатные) функции **обрабатывают набор строк и возвращают одно значение**.

| Функция (в конструкторе) | SQL | Что делает | Пример |
|---|---|---|---|
| **Сумма** | `SUM` | Сумма значений | Суммарный оклад по должностям |
| **Среднее** | `AVG` | Среднее арифметическое | Средняя оценка студента |
| **Минимум** | `MIN` | Наименьшее значение | Минимальный оклад |
| **Максимум** | `MAX` | Наибольшее значение | Максимальная оценка |
| **Количество** | `COUNT` | Число непустых значений | Число студентов на специальности |
| **Каждый / Любой / Некоторые** | `EVERY`, `ANY`, `SOME` | Логические функции для булевых значений | Реже используются |
| **Стандартное отклонение, дисперсия** | `STDDEV_POP`, `STDDEV_SAMP`, `VAR_POP`, `VAR_SAMP` | Статистические показатели | Разброс оценок |
| **Группировка** | `GROUP BY` | Не функция, а режим объединения строк в группы | См. вопрос 17 |

Набор функций зависит от версии LibreOffice и встроенной СУБД (HSQLDB).

**Важно:**
- `COUNT("поле")` не учитывает `NULL`, а `COUNT(*)` считает все строки;
- в одном запросе с групповой функцией все остальные поля должны быть либо **сгруппированы**, либо **агрегированы**.

**Пример:** средняя оценка по каждой дисциплине.

```sql
SELECT "Дисциплина"."Название", AVG("Успеваемость"."Оценка") AS "Средний балл"
FROM "Успеваемость", "Дисциплина"
WHERE "Успеваемость"."Дисциплина" = "Дисциплина"."ID"
GROUP BY "Дисциплина"."Название"
```

## 17. Для чего используется функция «Группировка»?

**«Группировка»** объединяет записи с **одинаковым значением выбранного поля** в одну строку результата. Для каждой такой группы групповые функции считаются **отдельно**.

Зачем нужна: получить итоги **по категориям**, а не по всей таблице.

**Пример:** сколько студентов на каждой специальности.

Без группировки `COUNT` вернёт одно число для всей таблицы (общее число студентов). С группировкой по `Специальность` получим по строке на каждую специальность:

| Специальность | Количество студентов |
|---|---|
| 010101 | 12 |
| 010302 | 9 |

**Как настроить:**
1. Включить строку «Функция» (значок Σ).
2. Для поля, по которому делим на группы, выбрать **«Группировка»**.
3. Для поля, которое считаем, выбрать функцию (`Количество`, `Среднее` и т. д.).

## 18. Как функция «Группировка» влияет на оператор SELECT?

При использовании группировки в SQL-запросе **появляется раздел `GROUP BY`**, а в списке `SELECT` остаются:

- поля, перечисленные в `GROUP BY`;
- групповые функции (`COUNT`, `SUM`, `AVG`, …).

**Правило:** любое поле в `SELECT`, не обёрнутое в групповую функцию, **обязано** присутствовать в `GROUP BY`. Иначе запрос выдаст ошибку.

**Сравнение:**

Без группировки:

```sql
SELECT COUNT("Номер_зачетки") FROM "Студент"
-- одна строка: общее число студентов
```

С группировкой:

```sql
SELECT "Специальность", COUNT("Номер_зачетки") AS "Количество студентов"
FROM "Студент"
GROUP BY "Специальность"
-- по строке на каждую специальность
```

**Условие на группы** задаётся не в `WHERE`, а в `HAVING`. В конструкторе это строка «Критерий» у поля с групповой функцией:

```sql
SELECT "Специальность", COUNT("Номер_зачетки") AS "Количество студентов"
FROM "Студент"
GROUP BY "Специальность"
HAVING COUNT("Номер_зачетки") > 10
```

**Порядок выполнения:** `FROM` → `WHERE` (отбор строк) → `GROUP BY` (формирование групп) → `HAVING` (отбор групп) → `SELECT` → `ORDER BY`.
